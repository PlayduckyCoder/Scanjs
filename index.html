ScanJS Documentation

Introduction

ScanJS is a lightweight JavaScript library to scan QR codes from images using drag and drop. It copies the QR code data directly to your clipboard.

Methods

load.SCANJS()

-- meaning: Loads the main ScanJS script and prepares it for scanning.

enable.drag.n.drop = true

-- meaning: Enables drag and drop support for image QR code scanning.

start.scan('qr.code', 'image-name')

-- meaning: Starts scanning the QR code in the dragged or selected image. Automatically copies the result to clipboard.

finish.scan('qr.code')

-- meaning: Ends the scanning session. Useful for cleanup or UI updates.

debug.fetch(SCANJS)

-- meaning: Debug tool to check if the ScanJS script is loaded properly.

Example Usage

<script src="scanjs.js"></script>
<script>
    ScanJS.load.SCANJS();          // Load ScanJS
    ScanJS.enable["drag.n.drop"] = true;  // Enable drag and drop
    ScanJS.start.scan('qr.code', 'myQR'); // Scan QR code from image
    ScanJS.finish.scan('qr.code');       // Finish scanning
</script>
